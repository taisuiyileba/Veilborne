# 天幕异闻 · 绯线缝世 1.4

适用：Minecraft 1.21.1 / NeoForge 21.1.248。模组文件为 `mods/veilborne-1.21.1-neoforge-1.7.1.jar`，与星海倒灌、月骸花潮、镜天巡礼是同一个模组，不需要其他前置。

> 天衣本无缝。只是每隔许多年，就有人来补一次。

## 马上体验

在允许作弊或具有管理员权限的世界中，站在主世界露天处输入：

```text
/veilborne scarletseam start
```

完整演出十三分钟，白天黑夜都可以（夜里最好看）。想直接看某个阶段，用百分比跳转：

```text
/veilborne scarletseam stage 12    裂天：天幕从中间撕开，缝里是没有星星的黑
/veilborne scarletseam stage 28    落针：金针一针一针缝合伤口，几秒后地上亮起第一处落针区
/veilborne scarletseam stage 54    缝世：金针落进大地、穿过地底再回到天上，随后拉线
/veilborne scarletseam stage 74    收线：线在天上打结、被剪断
/veilborne scarletseam stage 92    余线：缝线冷成金线，慢慢变成星带
```

缝世从 `stage 54` 开始看最完整：金针要先在你附近选好两处落点，跳到更晚的位置就没有缝地那一针。拉线（被轻轻牵动、万物头顶的线、叠影）大约在跳转后一分十几秒出现。

其他命令：

```text
/veilborne scarletseam status
/veilborne scarletseam start 180
/veilborne scarletseam stop
```

四种天幕异象同一时间只会有一个。开始一个时，正在进行的另一个会立即平稳结束。

## 一场缝世会发生什么

| 时间 | 阶段 | 你会看到 |
| --- | --- | --- |
| 0:00–1:00 | 引线 | 高处垂下一根根没有来处的红线；尘屑和线屑都往一个方向飘；天上闪过一道金色细缝 |
| 1:00–3:00 | 裂天 | 天空变成一整匹垂挂的绯红丝绸；那道细缝从中间撕开，边缘烧着金红的火，缝里是没有星星的黑，几根断线垂进缺口 |
| 3:00–7:00 | 落针 | 一根比山还长的金针从缝的另一侧伸出，每穿一针，地平线先亮起一道细光，稍后才传来织机声；红线在伤口上拉成针脚，一针比一针紧 |
| 7:00–9:30 | 缝世 | 金针落进你附近的大地，从地底穿过，在两百格外破土而出，把世界缝到天上；一只看不见的手的影子掠过天幕与大地，把线拉紧 |
| 9:30–11:30 | 收线 | 线在天上打成一个结，被剪断，线头垂落；金针退回缝里 |
| 11:30–13:00 | 余线 | 缝线冷成一道金线，慢慢化作一条普通的星带；最后一小片天落到你身边 |

白天的天幕是朱红的丝，夜里是深绛色，丝的褶皱间有暗金的微光和星点。

## 在缝线之下

- **天幕是布：** 天空整个变成垂挂的丝绸，褶皱从天顶垂到地平线，会被慢慢拽向伤口。伤口固定在大地上空，你走动时它不会跟着你走，所有人看到的是同一道伤口。
- **针脚：** 每一针都穿过伤口两侧真实的针眼：针从背面穿出、在前面拉过、再从背面回去，背面的线只在缺口里隐约可见。缝上的部分是一道发热的缝线，拉线时整条缝会亮起来。
- **地平线细光：** 金针每刺穿一次天幕，远处地平线上都会跑过一道细光；织机声按距离晚一点才到。
- **万物被牵动：** 线屑和尘埃偏向针所在的方向；缝世时偏向缝地的那条线。
- **金色接缝：** 附近岩壁和树干上会裂开片刻的金色接缝，一粒小火花沿着它缝过去，缝过就消退。方块本身不会改变。
- **室内：** 屋里看不到天幕，只有梁下细线的低振和门窗透进的一点绯光；不晃镜头。
- **动物：** 附近的原版动物会望向金针；拉线时它们站住不动，昂着头。
- **声音：** 天上是一层低沉的弓弦长音，底下垫着一片无词的合唱。引线时一根低弦被拨响、音高往下压弯，很远的地方织机应了一声；裂天时布帛慢慢撕开，底下有一声闷哼。落针时每一针都有针穿布的嘶声和一丝细细的金属颤音，远处的织机（筘的闷响、综片的木声、梭子的叹息）按距离晚一点才到。落针区预告时一根弦越拧越紧，然后骤然静下；针落是一声闷雷和绷断的弦。拉线时是一根天那么大的弓弦在颤，合唱随之升起；缝世时会断续传来一段织歌。收线时线结拉紧、一声木叩，剪刀合拢；余线时一个回到 D 的和弦慢慢散开。

## 来客与奇遇

### 落针区

落针阶段，金针会三次落到地上，缝世时它的两只脚也会落在地上。每一处都先有预告：

1. 地上亮起一圈宽阔的符线（针脚、十字绣、向心螺旋和针眼），尘屑向中心旋，声音越收越紧，符线由金变红。
2. 大约六秒后（缝世的两脚约五秒），一束光先从天上聚到中心，然后针落下，扫开一圈冲击带。
3. 走出圈外就没事，并会得到"读懂了落针的预告"的记录；留在圈里会被击倒并被抛出圈外（约两颗心），带着**系缚结**或站在**调律锚**旁则只受伤、不会被抛动。

落针只选露天空地，不会落在你头顶，也不会损坏任何方块。落过针的地方留下一根连着天上的红线，一个小线结钉在地上。

### 走针者

有时一只六足的黄铜之物会顺着第一针留下的红线爬下来。它收拢地上掉落的线头，然后回到线脚下坐着打结。它不会主动招惹任何人。

- 碰一碰它的线结（右键或攻击），线结散开，三个线头飞到空中，它转身追你、用针尖刺你。
- 抢在它之前接住三个线头：每个线头给一截**绯线**，三个都接住，线结的芯留在你手里——一缕**时缝残丝**，并得到观测记录。
- 每只走针者的线结只能解开一次。线被剪断时它会把自己卷起离开。

### 未缝合的口袋

金针离开大地之后，缝地那一针的落点附近会留下一小块没缝上的地方：地上一圈旧金色的光，风吹不进去，线屑绕开它；里面漂着一些旧东西的影子（织机、铃、钟、灯、罗盘……），像褪色的旧照片。

- 在口袋里放下一只**调律锚**，旧物会慢慢聚向它；约十六秒后收成三缕**时缝残丝**，并得到观测记录。
- 放下调律锚的同时会惊醒三只**线灵**：由红线缠成的小团，会追着人啄（每下半颗心），被打散时掉一截绯线。口袋收成残丝时，它们也随之散成线；和平难度下不会出现。
- 锚放在口袋外面没有任何作用。口袋在余线快结束时合上。

### 游离的线头

落针与缝世时，天上会不时放下一截线头，慢慢飘落，一边飘一边偏向缝线。接住它（或等它落地再捡）就得到**绯线**。每人每场最多八截。

### 缝合一个瞬间

拉线的那几秒，世界会叠出刚刚过去的几秒，像几层胶片；每个人、每只动物头顶都连着一根通到天上的线。这只是画面，不会回滚背包、方块、血量或时间。觉得不适可以在客户端设置里关掉（见下文）。

拉线时，露天的人会被轻轻牵向缝地的那条线，脚下微微离地。带着系缚结或站在调律锚六格内就不会被牵动。

另有一条隐藏记录，与那根线有关。

### 最后一片

缝线冷成星带时，会有一小片天落到你附近：**天衣残片**，一小块缀着星星的深蓝布料，边上还缝着绯线与金线。

## 观测手记

第一次见到天幕裂开时会自动获得手记（已有手记则不重复发放），书页顶端多出一条绯红书签。点击书签或按 **Tab** 在已发现的章节之间切换。绯线缝世一章有四个跨页：异象纪要与实时时间轴、来客与奇遇及缝余之物、工艺、观测记录与守则。

六条公开的观测记录：

1. 天幕裂开了。
2. 见证世界被缝上。
3. 读懂了落针的预告。
4. 接住一截游离的线头。
5. 解开走针者的线结。
6. 调好了未缝合的口袋。

另有一条隐藏记录。

## 自然出现

绯线缝世白天黑夜都可能开始，与另外三种天气共用平静期：一场异象结束后，要再过几个游戏日才会有下一场。几种天气都开启时，此刻能开始的那几种机会均等（月骸花潮只在入夜后参与）。每场会随机带上走针者或未缝合的口袋之一，或两者都有。

## 设置

`config/veilborne-client.toml`：

- `threadStrings`：拉线时每个活物头顶通到天上的线。
- `threadMoment`：拉线时叠出过去几秒的画面（多层胶片）。
- `threadSeams`：岩壁与树干上的金色接缝。
- 画质、天空、天光染色、效果亮度、音量等与另外三种天气共用。

`saves/<世界名>/serverconfig/veilborne-server.toml`：

- `naturalScarletSeam`：自然出现。
- `scarletSeamDurationSeconds`：持续时间，默认 780 秒，范围 120–3600。
- `threadStrikes`：落针区（关掉后三次落针留在天上，不再落到地上；缝世仍然发生，但两只脚不伤人）。
- `threadVisitors`：走针者与未缝合的口袋。
- `threadTug`：拉线时的轻微牵引。

多人游玩时，服务器与每名玩家需要安装相同版本的模组。

## 世界规则

- 不破坏建筑，不清空容器，不强行把任何人带走；落针、缝地的两只脚、口袋和最后一片都只选露天的安全空地，不会出现在岩浆、水中、虚空或建筑内部。
- 落针只伤害留在预告圈里的人，而且预告一定在前；创造与旁观模式不受影响。拉线只是很轻的牵引，会取消摔落伤害。
- 天上垂下的线头在天气结束时会恢复正常重力，不会一直悬在空中。
- 离开天气区域，天色与声音会平滑恢复。

## 1.7.0：留下的东西与完整度

- **缝在一起的灯**：收线时两处落针点各留一盏相连的织天灯（远的那盏在你走近或第一次顺线过去时才落下）。空手右键一盏，一秒半后被线牵到另一盏；潜行右键只看方向和距离。
- **自己缝传送网**：拿绯线先后右键两盏织天灯就缝在一起，每 64 格用一根绯线。打破一盏，线就断了。
- **护线或剪断**：拉线之前站在两处落针点之间的线上，是替它绷紧；拿剪刀在落针点附近右键，是剪断它——这一次世界不被缝上，也没有那对灯，但留下六根绯线和一缕时缝残丝。两者只能选一个。
- **针芯（险路）**：带着系缚结站到落针符环的正中央，承受 8 点无视护甲的伤害，接住一截针芯；缝灯时带着它，只用一根线，而且能缝到另一个维度。
- **完整度**：看着世界被缝上、读懂预告、接住线头、解开线结、调好口袋、护线或剪断，另有险路（2 点）与隐藏一项。三星（5 点）余赠四根绯线和一盏织天灯。

完整的说明（完整度的每一项、余赠、险路的细节）见 `余泽与完整度_使用说明.md`。
