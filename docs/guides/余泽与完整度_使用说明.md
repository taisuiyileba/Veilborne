# 天幕异闻 · 余泽与完整度（1.7.0）

适用：Minecraft 1.21.1 / NeoForge 21.1.248。模组文件为 `mods/veilborne-1.21.1-neoforge-1.7.1.jar`。

1.7.0 之前，六种天幕异象主要是看的：看完拿到几件纪念品，用处不大。1.7.0 做了三件事：

1. **余泽**：每种天气都对应原版里一个真实的需求（探索、夜晚与怪物、寻宝、远距离交通、古城与潜行、农业与牧场），结束后在世界里留下能反复使用的东西。
2. **完整度**：每场结束时按你做了什么，给一到三颗星，写进手记，并按星级给一份"余赠"。有几处机制从"对不对"改成了"做得好不好"。
3. **险路**：默认仍然安全；想要更好的东西，可以选一条危险的路走。

手记每一章新增了第五个跨页（第 9、10 页）：左页"留在世上的"写这一章的余泽和你的标记（坐标），右页"完整度"显示这一场（进行中）或上一场的星级、每一项做没做到、最好成绩，以及二星、三星各给什么。

## 余泽：天气留下的东西

| 天气 | 对应的需求 | 留下的东西 |
| --- | --- | --- |
| 星海倒灌 | 探索 | **无海之舟远航**：坐在船头按住前进键，老翁朝你看着的方向，把你送到那边最近的沉船、海底废墟、海底神殿或远古城市上空，并给你一枚**归岸贝**回家。**星潮池**：鲸鳞落下的地方，四十格内的水在三天里能钓到星海的东西 |
| 月骸花潮 | 夜晚与怪物 | **月下安地**：银花灯周围二十四格，黑暗里不再冒出怪物。**月隐药水**：月露酿造，怪物很近才会注意到你 |
| 镜天巡礼 | 寻宝 | **镜中之塔的地基**：镜里多出来的那座塔，脚下真的埋着一间石室和一只箱子。**裂镜之心**：捏碎后，附近藏着的箱子和刷怪笼透过地面显形 |
| 绯线缝世 | 远距离交通 | **缝在一起的灯**：缝世的两处落针点各留一盏织天灯，彼此连着线，空手点一盏就被牵到另一盏；玩家也能用绯线自己缝，组成传送网络。**针芯**：跨维度缝线 |
| 无声白昼 | 古城与潜行 | **无声提灯**：拿在手里时，幽匿感测体、尖啸体、监守者都听不见你。**静烛**：六格之内什么声音都传不到幽匿方块 |
| 苍翠梦潮 | 农业与牧场 | **梦树心**：梦种长成的树，周围作物长得快一倍，幼崽长大、再次繁殖也快一倍，还常生双胞胎。**梦叶**：所有动物都吃，也能堆肥 |

### 星海倒灌

- **远航**：无海之舟现在停留约两分钟。登船后，面向你想去的方向，**按住前进键约一秒半**。老翁调转船头，小船升进星海，画面沉进一片星光里；几秒后你被放在目的地上空，身上带着缓落。
  - 目的地是"那个方向三百二十格外那一点"附近最近的**沉船、海底废墟、海底神殿或远古城市**（数据包标签 `veilborne:skiff_voyage`，整合包可以改）。
  - 去海里的，身上带着三分钟**水下呼吸**；去远古城市的，被放在它正上方的地面，带一分钟夜视——城在很深的地下，要自己挖下去。
  - 老翁会把一枚**归岸贝**放进你手里。右键使用，潮声把你送回上船的地方；只能用一次，只在同一维度有效。提示框里写着它通往的坐标。
  - 远航途中潜行下船就取消。那个方向找不到任何地方时，老翁会摇头，你还在船上。
  - 去过的地方记在手记"你的标记"里。
- **将熄的鲸鳞**：古鲸经过后，光柱落地处散落**五枚**鲸鳞，每一枚都在**四十五秒**内一点点熄灭（光点越来越少），熄灭就没了。捡到三枚、五枚都算进完整度。星螺仍然留在中间，不会熄。
- **星潮池**：鳞片落下的地方会留下一片星潮，持续**三个游戏日**，地面上的水面会飘起细小的星屑。在它**四十格**以内的水里钓鱼，每次上钩有 45% 的机会**额外**钓上一件星海里的东西：鲸鳞、鹦鹉螺壳、海晶砂粒、发光墨囊、星潮瓶、星螺、海洋之心（很少）、附魔书（海之眷顾、饵钓、深海探索者、水下呼吸），以及**卷着海图的漂流瓶**。附近没有水，就自己挖个池子、倒桶水。池子的坐标和剩余天数记在手记里。
- **卷着海图的漂流瓶**：打开后得到一张**星海藏宝图**，标着最近一处还没人找到的埋藏的宝藏（原版的红叉宝藏图）。找不到时，瓶里就是一瓶普通的星潮。

### 月骸花潮

- **月下安地**：**银花灯**（送月人留在路边的那盏，或自己合成的）周围**二十四格**内，黑暗里不再自然生成任何怪物。刷怪笼、刷怪蛋、召唤、袭击不受影响。放在家门口、牧场、刷铁机旁都可以。
  - 1.7.0 之前就放下的银花灯，会在一两分钟内自己登记生效。
- **月隐药水**：在酿造台里把**月露**加进**粗制的药水**，得到月隐药水（3:00）；再加红石延长到 8:00。可以做成喷溅型、滞留型和药箭。喝下后，怪物要走到你原本被发现距离的四分之一才会注意到你；已经在追你的，你离它超过十格就会跟丢。适合夜里赶路、下矿。
- **越早认出真月，残留的月光越多**：三月同天一开始就认出真月，得到三片月瓷片和两瓶月露；拖到快合月时只剩一片瓷片。月仪会报出"残留的月光：几成"。

### 镜天巡礼

- **镜中之塔的地基**：倒影出现后（覆镜之后到裂镜之前），镜里多出一座塔。抬头找到它，**举起观测棱镜对准塔在地面上站的位置**（棱镜里能看到它的淡青轮廓），**约一秒多**，塔影就会伸进地下。从塔的正中往下挖四五格就碰到石室的顶，里面是一间旧石室：石砖墙、磨制深板岩地面、一座方解石台上的紫水晶簇、两盏灯，和一只**箱子**。
  - 箱子里：镜砂、紫水晶、金锭、绿宝石、钻石（一到三颗）、附魔之瓶、命名牌、望远镜、金苹果、青金石，必有一本 20–30 级的附魔书，还有机会是回响镜、天镜残片或观测棱镜。
  - 石室只从天然的地层里挖出来。塔下如果有人造的东西，石室会更深；还挡着，就只放一只箱子。
  - 塔基的坐标记在手记里，天气结束后也能回去挖。
- 棱镜的判定顺序：先是多出来的门，再是近处的镜框，然后才是远处的塔。

### 绯线缝世

- **天气留下的一对灯**：线被剪断、收结时，缝地的两处落针点（相隔约两百格）**各放下一盏织天灯**，两盏之间连着那根线。远的那一盏常常在没加载的地方：你走过去、或者第一次顺线过去时，它才落下。
- **顺线过去**：**空手**右键一盏已经缝好的织天灯，绯线收紧，站着别动，一秒半后你就站在另一盏旁边（带两秒缓落）。走开就取消。**潜行右键**只看不走：会告诉你另一头在哪个方向、多远。
- **自己缝**：拿着**绯线**右键一盏织天灯（线头系上），再拿着绯线右键另一盏，两盏就缝在一起。距离每 **64 格**用一根绯线（至少一根），不够会提示还差几根。再点第一盏可以解开线头。一盏灯只有一个另一头，重新缝会剪断旧的；打破一盏，另一盏的线也断了。
  - 织天灯的配方不变（时缝残丝、两根绯线、灯笼、金锭）。把几盏灯放在家里、矿洞口、村庄、下界门旁，就是一张传送网。
  - 远处的织天灯会有一根红线升进天空，指向另一头；缝到别的维度的，线笔直向上。
- **针芯**：缝灯时身上带着一截针芯，不论多远**只用一根绯线**，而且**可以缝到另一个维度**（主世界 ↔ 下界 ↔ 末地）。每缝一次用掉一截。针芯只能从下面的"险路"得到。

### 无声白昼

- **无声提灯**：拿在主手或副手时，你走路、跑跳、放方块、挖方块、开箱子、射箭（箭落地）都**不会被幽匿感测体、尖啸体、监守者和悦灵听见**。于是远古城市终于能走进去了——但监守者还会嗅，靠得太近照样被发现。
- **静烛**：放下后，**六格之内**任何来源的振动都被吞掉。点在尖啸体旁，它再也叫不出来；点在宝箱旁，开箱不会惊动什么。旧存档里已经放下的静烛会在一两分钟内自己生效。
- 远航能把你送到远古城市上空，两种天气正好接在一起。

### 苍翠梦潮

- **梦树心**：梦种、饱满梦种长成的梦树，树干最底下那格是**梦树心**（有一个琥珀色的结，会飘花粉）。只要树冠还有叶子，每两秒它会：
  - 让周围 **8 格**（饱满梦种的树 **12 格**）、上下三格内的作物、树苗、瓜梗、浆果、甘蔗、仙人掌、竹子、可可、下界疣、发光浆果**多生长一次**，大约是原来的两倍速度；
  - 让范围内的**幼崽长大快一倍**、刚繁殖过的动物**恢复快一倍**；
  - 繁殖时有 30%（饱满梦种的树 45%）的机会**生下双胞胎**；
  - 偶尔自己落下一枝**梦叶**。
  - 梦树心打破后变回梦树原木，不能搬走。树冠被砍光，它就睡着了。1.7.0 之前长成的梦树没有心。
- **梦叶**：**所有动物都吃**。右键大的动物，它会进入求偶状态（青蛙、美西螈、海龟、兔子……不用再找各自的食物）；右键幼崽，它长大一些。放进堆肥桶 85% 成层。

## 完整度

- 在一场天气的区域里出现过，就算"见证"，至少一颗星。
- 每种天气有七到九项"做到的事"，大多数值 1 点，几项值 2 点（最难的、或者危险的）。二星需要 3 点；三星星海需要 6 点，月骸、镜天、缝世、梦潮 5 点，白昼 4 点。**不走险路、不靠隐藏项，也一定能拿到三星**——即使这场只来了部分来客。
- 天气结束（自然结束、被命令停止或被另一种天气替换）时结算：聊天栏里出现"【月骸花潮 · 完整度 ★★☆】"、这一场做到了什么，以及余赠。结算时不在线的人，下次登录时补上。
- 同一时间只记一场。手记右页"完整度"显示进行中的这一场（实时更新），或者上一场；"最好"是这种天气的历史最好。隐藏的项目在做到之前不会列出。

| 天气 | 二星余赠 | 三星余赠 |
| --- | --- | --- |
| 星海倒灌 | 星鲸鳞 ×1 | 星鲸鳞 ×2、卷着海图的漂流瓶 ×1 |
| 月骸花潮 | 银花灯 ×1 | 银花灯 ×2、月露 ×2 |
| 镜天巡礼 | 镜砂 ×4 | 镜砂 ×6、透光镜 ×1 |
| 绯线缝世 | 绯线 ×3 | 绯线 ×4、织天灯 ×1 |
| 无声白昼 | 白昼蜡 ×2 | 白昼蜡 ×2、无声提灯 ×1 |
| 苍翠梦潮 | 梦种 ×1、梦树叶 ×4 | 饱满梦种 ×1、梦树叶 ×8 |

各天气算进完整度的事：

- **星海倒灌**：见证古鲸越过天穹；登上无海之舟；随浮潮升起；打开抵岸的漂流瓶；接住三枚将熄的鲸鳞（2 点）；一枚鳞也没让它熄灭；随老翁远航。
- **月骸花潮**：目送月壳剥落；与送月人同行；接住月露；看见只在一处成立的星座；辨认真月；趁月光还多时辨出真月（前一半时间内）；（隐藏）空位里有人向你挥手。
- **镜天巡礼**：巡礼者从头顶走过；找到多出来的门；镜中的你取来回响镜；认出照着此刻的镜子；跟上迟到的旅人；找到镜中之塔的地基；【险】打完整整两波镜兽（2 点）；（隐藏）巡礼者认出了你。
- **绯线缝世**：看着世界被缝上；读懂落针的预告；接住三截线头；解开走针者的线结；调好未缝合的口袋；站在线上替它绷紧；剪断缝地的线；【险】落针圈正中接住针芯（2 点）；（隐藏）看见牵着你的线。
- **无声白昼**：蚀时站在露天；回应门外的敲门声；向无声行列举灯；找到唯一的声音；等到迟来的雷；【险】在寂静里出声，并活到了鸟叫（2 点）；（隐藏）黑日听见了你。
- **苍翠梦潮**：巨鹿从身边走过；沿花路走到梦树下；巨鹿低头看了你一眼（2 点）；把梦种引到泥土上；把失路的叶鱼带回天上；走完梦藤围场；（隐藏）梦种落进了巨鹿的蹄印。

### 绯线缝世的两种结局

金针从大地的另一头破土、回到天上之后，到看不见的手把线拉紧之前（约半分钟），有一个选择：

- **护线**：拉线的那一刻站在两处落针点之间的那条线上（四格以内），就是在替它绷紧。世界被缝上，结束时留下那一对织天灯。
- **剪断**：拿着**剪刀**在任一处落针点附近（八格内）右键。线断了：不会有拉线、万物之线和胶片残影，世界这一次不被缝上，也**不会留下那对灯**；但你脚下落了六根绯线和一缕时缝残丝，够自己缝好几段路。

两种都算一项完整度，只能选一种。

## 险路

默认的一切仍然安全。下面三条路都要你自己选：

- **针芯（绯线缝世）**：落针区的预告亮起后，**带着系缚结**站到符环的**正中央**（1.6 格以内），等针落下。你会承受落针的全部重量——**8 点魔法伤害（四颗心，无视护甲）**，但系缚结让你不被抛开——然后手里留下一截**针芯**。血不够就别站。每场每人最多一截。
- **两波镜兽（镜天巡礼）**：让镜兽的裂片炸开，把第一波三只**全部打死**，而且人还留在裂片附近，碎渣会重新聚成**第二波五只**。第二波也打完，裂片中心留下一颗**裂镜之心**（每场最多两颗，一个裂片一颗）。镜兽自己碎掉的不算。
  - **裂镜之心**：右键捏碎，半分钟内，**三十二格**里的箱子、木桶、潜影盒、刷怪笼、试炼刷怪笼、宝库、可疑的沙子和沙砾、饰纹陶罐会透过地面和岩壁，以银色的框显出来。
- **在寂静里出声（无声白昼）**：世界褪成灰色以后、第一只鸟叫之前，**故意**发出声音——敲钟、弹音符盒、吹山羊角、放唱片——声音会在寂静里传得很远，地底下有什么翻了个身。五秒后，一只**监守者**从你身边的地里爬出来，而且已经被激怒。
  - 撑到第一只鸟叫（复声），它会慢慢钻回地下，你得到**四片回响碎片和两块白昼蜡**；把它打死也一样（它本身还会掉幽匿催发体）。
  - 每场只会被听见一次。和平难度下什么都不会来。拿着无声提灯时你发不出这种声音。
  - 监守者不破坏方块，但非常危险：请在远离家的地方试。

## 手记新页

- 左页"留在世上的"：这一章的两项余泽，以及"你的标记"——星潮池（坐标、还剩几天）、远航到过的地方、塔基宝箱的坐标、织天灯两端的坐标。最多记八处，过期的星潮池会自动消失。
- 右页"完整度"：大星星是这一场（进行中）或上一场的星级；下面是点数和二星、三星的门槛；每一项做到了会点亮，值 2 点的在右边写着 +2，险路标着【险】；最后两行是二星、三星的余赠。

## 兼容与注意

- 远航和海图需要在世界里搜索结构，第一次可能让服务器顿一下（和 `/locate` 一样）。
- 星潮池只在主世界有效。月下安地、静烛、梦树心在任何维度都有效。
- 织天灯被活塞推动或爆炸破坏时，线会断。
- 升级到 1.7.0 后，旧存档里已有的银花灯、静烛会自动生效；已有的梦树没有树心（重新种一棵）。
