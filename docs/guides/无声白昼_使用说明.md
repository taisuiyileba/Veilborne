# 天幕异闻 · 无声白昼 1.5

适用：Minecraft 1.21.1 / NeoForge 21.1.248。模组文件为 `mods/veilborne-1.21.1-neoforge-1.7.1.jar`，与星海倒灌、月骸花潮、镜天巡礼、绯线缝世是同一个模组，不需要其他前置。

> 世界彻底安静以后，门外传来了唯一的一次轻敲。

## 马上体验

在允许作弊或具有管理员权限的世界中，站在主世界露天处输入：

```text
/veilborne silentday start
```

完整演出十二分钟，白天黑夜都可以（夜里蚀的是月亮）。想直接看某个阶段，用百分比跳转：

```text
/veilborne silentday stage 6     失声：音乐先停，然后是风、洞穴与动物，最后连自己的脚步也没了声音
/veilborne silentday stage 16    褪色：灰色从地平线漫到脚下，世界褪成浅灰
/veilborne silentday stage 36    黑日：黑日从北方升起，颜色一缕缕流进它
/veilborne silentday stage 60    蚀：黑日盖住那轮白色，天不暗反白
/veilborne silentday stage 72    迟雷：几秒后地平线上立起一道笔直的白线，半分钟后雷声才到
/veilborne silentday stage 88    复声：第一只鸟叫了，羽毛落下，颜色从你身边向外回来
```

看黑日盖住太阳要从 `stage 55` 前后开始：黑日需要时间从北地平线升到大圆上的太阳处，跳得更晚就错过了靠近的过程。

其他命令：

```text
/veilborne silentday status
/veilborne silentday start 300
/veilborne silentday stop
```

六种天幕异象同一时间只会有一个。开始一个时，正在进行的另一个会立即平稳结束。

## 一场无声白昼会发生什么

| 时间 | 阶段 | 你会看到 |
| --- | --- | --- |
| 0:00–1:00 | 失声 | 音乐先停，然后是风、洞穴与动物；方块声被闷住，最后连自己的脚步也没了声音。云越飘越慢，风停在林边，尘埃、落叶和水珠停在半空 |
| 1:00–3:00 | 褪色 | 天空被一幅冻住的苍白正午盖住，太阳变成没有光晕的纸白圆盘。灰色像潮水一样从视野边缘漫到脚下，世界被提亮成浅灰，只有灯火旁留下一点旧照片般的暖黄 |
| 3:00–6:15 | 黑日 | 一颗不发光的黑日从北方地平线升起，沿大圆靠近那轮白色；它周围的天空像透镜一样弯曲，世界的颜色从四周地平线化作细带流进它 |
| 6:15–8:30 | 蚀 | 黑日盖住白日：天不暗反白，一圈爱因斯坦环一闪而过，然后是张开的黑色日冕。大地没有影子，动物站住仰头，灯火最后一点暖色也熄了 |
| 8:30–10:30 | 迟雷 | 黑日沉回北方，颜色细带倒流回地平线。地平线上立起一道笔直的白线，消失后留下暗色的残像 |
| 10:30–12:00 | 复声 | 纸白圆盘退去，最后天空恢复颜色。先是一只鸟，再是脚下的草，颜色从你身边向外回来 |

## 在寂静之下

- **寂静是一层层退去的：** 音乐最先，然后是风与洞穴、动物、方块（被闷住，不是消失），最后是自己的脚步。本模组自己的声音、主音量和敌对生物不受影响；受伤声和字幕始终保留。
- **褪色是画面上的：** 世界被压成提亮的浅灰，灯火旁不是还原原色，而是旧照片般的棕黄；无声提灯、提灯的行列，以及举起灯的一闪透出更多颜色。有声岛、铃声的波纹和脚印处是完整颜色。蚀的时候大地再被漂白一层。
- **黑日不发光：** 它没有光晕，没有亮度，只是一块黑；它周围的天空被弯折，冻住的云和天空绘画会绕成弧，白色圆盘在它背后时环成一圈光。天光不会变暗。
- **云停住又接着走：** 云是减速停住的，演出结束后从停下的地方接着飘，不会跳回原来的位置。
- **室内：** 屋里看不到褪色以外的天空，只有门窗处立着的苍白光柱和停在光里的尘埃；不晃镜头。
- **动物：** 附近的原版动物会望向黑日；蚀的时候它们站住不动，昂着头。
- **声音：** 开头是一口吸进去不再呼出的气；褪色时一段玻璃琴一路滑进无声，耳中留下一线几乎听不见的低鸣。远处每过很久才有一段低得几乎听不见的和声。蚀的瞬间有一声心跳，之后是近五十秒的全然寂静，松开时一声轻响。白线出现三十四秒后，远处才传来一声低沉的长雷。

## 来客与奇遇

### 举灯

在寂静里，灯就是你的声音。**手持火把、灯笼、萤石之类发光的东西，对着空处（不是方块）使用**，便举灯闪一下，同时在你手边点亮一小圈颜色。

- 无声行列和敲门的空位都会回应你。无声提灯照得更远（24 格，普通灯 12 格），还能照出**行列从不留下的脚印**。
- 两次举灯之间有一秒多的间隔，不必连点。

### 无声行列

一列旧时代打扮的旅人沿地面走过：提灯的、打伞的、提着空鸟笼的孩子、拄杖的老人、提箱子的高个子。他们的嘴在动，却没有声音，走路也不留脚印。队伍会从你身旁十几格经过，遇墙便像被擦去一样消失、在另一侧重新画出。

对着他们举起灯：最近的旅人会转身停下，把提灯举起来回应你，孩子的队伍里会给你留下一块**白昼蜡**。

### 敲门的空位

你在房子附近时，门外会站着一件没有人的长外套，隔一会儿轻敲三下，门上留下三圈涟漪。打开门，对它举起灯（需要看见它，玻璃可以隔着）：它会鞠躬，在门槛上留下两块**白昼蜡**，然后从帽子开始向下像被橡皮擦去一样消失，擦过的地方落下石墨色的碎屑。它从不自己开门，也不搬动任何东西。

### 唯一的声音

远处还有一只铃在响，悬在树下、岩边，或什么也没有的空中。它每响一次，就有一圈颜色穿过灰色的大地。

走到它跟前（2.8 格内）就算找到：周围十格恢复声音与颜色，成为一座**有声的小岛**，铃会隔一阵清脆地响一次。约一百一十秒后小岛合上，铃落下来，成为你的**空响铃**。

### 迟来的雷

黑日沉下去之后，地平线上会立起一道笔直的、没有分叉的白线，站在露天就能看见。它消失后留下暗色的残像，像明亮的东西留在眼睛里。三十四秒后，雷声才从远处传来。它不造成伤害，只是让声画之间隔得极不自然。

### 黑日听见你

蚀的时候站在露天，抬头正对着黑日（视线的八度以内），举起灯：它的边缘会亮起一圈琥珀色，作为回应。这是一条隐藏记录。

## 自然出现

无声白昼白天黑夜都可能开始，与另外五种天气共用平静期：一场异象结束后，要再过几个游戏日才会有下一场。几种天气都开启时，此刻能开始的那几种机会均等（月骸花潮只在入夜后参与）。

## 设置

`config/veilborne-client.toml`：

- `hushSilence`：让无声白昼让世界失声（音乐、风、动物、方块与脚步）。警告、敌对生物、受伤声与字幕始终保留。
- `hushFade`：让无声白昼从世界里抽走颜色；灯火保留一点棕黄。
- `hushMotes`：身边停在半空的尘埃、落叶与水珠。
- `hushBlur`：颜色不在时把远景稍微揉软。
- 画质、天空、天光染色、效果亮度、音量等与另外五种天气共用。

`saves/<世界名>/serverconfig/veilborne-server.toml`：

- `naturalSilentDaylight`：自然出现（昼夜皆可）。
- `silentDaylightDurationSeconds`：持续时间，默认 720 秒，范围 120–3600。
- `hushVisitors`：无声行列、敲门的空位和唯一的那只铃。

多人游玩时，服务器与每名玩家需要安装相同版本的模组。

## 世界规则

- 不破坏建筑，不清空容器，不强行带走任何人。生物 AI、红石、投射物和游戏时钟照常运行；离开的只有声音和颜色，而且只影响本模组的天气表现。
- 无声行列与敲门的空位都不会开门、不会拿取任何东西，也不会攻击；血量和饥饿不受影响。
- 迟来的雷、黑日和蚀都不造成伤害。
- 处于天气区域之外、或把客户端效果关掉时，天色与声音会平滑恢复。
- 空响铃只保存一场天气的声音：在另一场异象中摇响，会换成那一场；平时摇响只放出声音，不影响任何玩法。

## 1.7.0：留下的东西与完整度

- **无声提灯**：拿在手里时，走路、挖放方块、开箱子都不会被幽匿感测体、尖啸体、监守者听见（监守者仍然会嗅）。远古城市终于能走进去了。
- **静烛**：六格之内任何振动都传不到幽匿方块。旧存档里已放下的静烛会自己生效。
- **在寂静里出声（险路）**：世界褪色以后、第一只鸟叫之前，故意敲钟、弹音符盒、吹山羊角或放唱片，五秒后一只已被激怒的监守者从你身边的地里爬出来。撑到鸟叫它钻回地下，你得到四片回响碎片和两块白昼蜡。每场一次，和平难度下不会来，请远离家试。
- **完整度**：蚀时站在露天、回应敲门、向行列举灯、找到唯一的声音、等到迟来的雷，另有险路（2 点）与隐藏一项。三星（4 点）余赠两块白昼蜡和一盏无声提灯。

完整的说明（完整度的每一项、余赠、险路的细节）见 `余泽与完整度_使用说明.md`。
