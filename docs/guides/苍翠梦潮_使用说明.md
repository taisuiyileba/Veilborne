# 天幕异闻 · 苍翠梦潮 1.6

适用：Minecraft 1.21.1 / NeoForge 21.1.248。模组文件为 `mods/veilborne-1.21.1-neoforge-1.7.1.jar`，与星海倒灌、月骸花潮、镜天巡礼、绯线缝世、无声白昼是同一个模组，不需要其他前置。

> 云里长出了一片倒悬的森林。有一头鹿，托着整片林子，从树根上走了过去。

## 马上体验

在允许作弊或具有管理员权限的世界中，站在主世界露天处输入：

```text
/veilborne dreamtide start
```

完整演出十三分钟，白天黑夜都可以（夜里是萤火与荧光的森林）。想直接看某个阶段，用百分比跳转：

```text
/veilborne dreamtide stage 4     绒云：云变得像绒毛一样软，边缘泛绿，种子的绒絮慢慢落下
/veilborne dreamtide stage 14    垂根：树根从云里垂下来，树冠一棵一棵从天顶向外长满
/veilborne dreamtide stage 30    叶海：倒悬的森林遮住整片天，叶鱼成群游过，附近长出一棵梦树
/veilborne dreamtide stage 50    鹿行之前：一条树根铺成的路垂到地上
/veilborne dreamtide stage 56    鹿行：巨鹿沿着树根之路走来
/veilborne dreamtide stage 77    落种：叶子转成金色一片片落下，梦种从天上降下
/veilborne dreamtide stage 91    归云：树根收回云里，鹿角枝落下，最后只剩一片普通的云
```

跳转会跳过中途的准备：想看巨鹿在梦树旁停下、低头看你，要从 `stage 30` 之前开始，让梦树和花路先长出来；巨鹿大约在 `stage 61` 停下，`stage 62` 前后低头。

其他命令：

```text
/veilborne dreamtide status
/veilborne dreamtide start 300
/veilborne dreamtide stop
```

六种天幕异象同一时间只会有一个。开始一个时，正在进行的另一个会立即平稳结束。

## 一场苍翠梦潮会发生什么

| 时间 | 阶段 | 你会看到 |
| --- | --- | --- |
| 0:00–1:00 | 绒云 | 云慢慢变软，像一团团绒毛，边缘泛起绿色；种子的绒絮从天上缓缓落下 |
| 1:00–3:00 | 垂根 | 树根从云里垂下来，生长的根尖亮着一点蜜色的光，最长的一直伸到山顶，用根须抓住地面。树冠从天顶开始一棵一棵长出来，新叶是明亮的嫩绿 |
| 3:00–7:00 | 叶海 | 倒悬的森林遮住整片天：从下面看上去，是一棵棵树的树冠，树与树之间留着缝，缝里是更深处的林子和透下来的光。叶影在地面和外墙上流动，叶鱼成群在空中游过，附近长出一棵发光的梦树 |
| 7:00–9:30 | 鹿行 | 一条树根铺成的路一段段垂到地上。巨鹿沿着它走来：身体几乎透明，像一团光凝成的鹿形，鹿角上长着一整片小树林，林中有灯和一座小屋。它每一步落下，地上都开出一圈花影 |
| 9:30–11:30 | 落种 | 每棵树在自己的时候转成蜜金色，叶子一片片落下，露出树枝的剪影；梦种从天上缓缓降下，悬在你头顶 |
| 11:30–13:00 | 归云 | 树根收回云里，鹿角枝落在你身边，梦树合上叶子，枝影淡进普通的云里，天空恢复原样 |

## 在倒悬的森林之下

- **森林是一整片的：** 头顶的森林固定在事件中心上空，大家看见的是同一片树冠；走动时，近处的树冠和更深处的林子会彼此错开。
- **叶影：** 露天的地面和外墙上会有叶影流动，树冠缝隙底下更亮；屋里只在门窗处透进一点。
- **花纹：** 花粉落下的地方、叶鱼俯冲过的草地和巨鹿的蹄印上，会亮起层层的花纹。巨鹿的蹄印会先亮很久，然后淡成一圈浅浅的花影，一直留到最后。
- **叶鱼：** 叶子像鱼一样成群游动、转弯，偶尔俯冲到地面化成花粉，再从树冠里落下新的叶子补上；窗台上偶尔会停一只。远处的高空还有大群在翻卷。
- **夜里：** 树冠变暗，最薄的叶子和树根里的脉络亮起一点荧光，萤火更多。
- **地下：** 在洞穴或矿道里，只能听见远处树根低沉的鸣响。
- **声音：** 风穿过头顶大片树叶的沙沙声，远处的水滴和不常见的鸟鸣；很久才有一段短短的簧管或拨弦。巨鹿的脚步很重又很轻，像敲在一只木碗上。

## 来客与奇遇

### 托林巨鹿

它的身体几乎透明，鹿角上长着一整片小树林。每场梦潮它都会从你附近走过一次，在梦树旁停下、转身、低头看一看，然后继续走远。它经过时站在露天就算见过它。

### 眠鹿回眸

梦树下的花路是给它走的。**在梦树 14 格内安静地站着**（五秒内不跑、不走远），等它停下来：它会低头看你一眼，稍后从鹿角间落下一颗**梦种**，落在你站着的地方。每场只有一个人能得到这一眼。

### 林中多了一条路

梦树长出来以后，发光的花瓣会沿着能走的地面排成一条路，从你身边通到梦树下。路会绕开墙、断崖、水和屋顶；走不通时这一次就没有路。**沿着花路走完大半，走到梦树下**，就算走到了尽头。

### 游荡的梦种与梦藤围场

一颗梦种会绕着农田里的作物（附近没有农田时绕着你身前）慢慢游动，从不碰作物。**碰一碰它**（走过去或对它使用），藤影会围着你长出一圈，身后留着一道出口。随后五道光一道接一道亮起：**在藤影合拢前追上每一道光**，就能得到一颗**饱满梦种**。走出圈外就算放弃，什么也不会失去；一道光太久没追上，藤影也会自己散去。每场只有一次。

### 失路叶鱼

一小群金色叶鱼游进了房子，挤在窗边出不去。**拿着花、树苗、花灯或一点光靠近它们**，它们会跟着你；把它们带到离窗户六格以外、四周空旷的露天处，它们会汇成一条金色大鱼游回天上，落下两片**金叶**。手里没有东西时它们会慢慢游回窗边。

### 落种

落种时，每个人头顶会先后降下三颗梦种，悬在离地一人多高处。**蹲下，或拿着花、树苗、一点光靠近**，梦种就会跟着你的手走；把它带到**露天的泥土、草地、苔藓或耕地**上方，它会落下来发芽，留给你一颗梦种。石头、水面和屋顶上它不会落下。

### 鹿角枝

树根收回的时候，巨鹿的鹿角上会落下一截小枝，落在你身边，枝头还长着一棵小树。

## 收获

| 物品 | 来源 | 作用 |
| --- | --- | --- |
| 梦种 | 眠鹿回眸、落种 | 种在露天的泥土、草地或苔藓上，会长成一棵小小的梦树。可以用骨粉催长 |
| 饱满梦种 | 梦藤围场 | 长成的梦树更高，叶缘镶金，有的开着蜜色的花 |
| 金叶 | 失路叶鱼 | 花灯的材料 |
| 鹿角枝 | 巨鹿的鹿角 | 挂在墙上的装饰（亮度 7），夜里会有萤火来 |
| 花灯 | 合成 | 金叶做的莲花苞，里面亮着灯（亮度 13），可以放在地上或挂在下面。周围一直有一小群叶鱼绕着它游，点一下收回，再点一下放出来 |
| 漂叶坠 | 合成 | 带在身上，从三格以上坠落时会像叶子一样慢慢飘下；每次坠落消耗一点，共 40 次 |
| 鹿鸣笛 | 合成 | 在主世界露天吹响，消耗它唤来一场完整的苍翠梦潮；已有异象或头顶有遮挡时不会消耗 |
| 梦树原木、梦树叶 | 种出来的梦树 | 梦树叶自己发着柔和的绿光（开花的更亮），不会枯萎、不会掉落、也不会蔓延 |

梦树只在你亲手种下梦种的地方长出来。天上的森林、树根、花路和临时的梦树都只是景象，不会放下任何真实的方块。

## 自然出现

苍翠梦潮白天黑夜都可能开始，与另外五种天气共用平静期：一场异象结束后，要再过几个游戏日才会有下一场。几种天气都开启时，此刻能开始的那几种机会均等（月骸花潮只在入夜后参与）。每场的奇遇组合不完全相同：花路、梦藤围场、失路叶鱼中通常会出现两到三种。

## 设置

`config/veilborne-client.toml`：

- `dreamDapple`：倒悬森林下地面和外墙上流动的叶影。
- `dreamLeafFish`：在身边空中游动的叶鱼群。
- `dreamPatterns`：花粉落下处和巨鹿蹄印上亮起的花纹。
- 画质、天空、天光染色、效果亮度、音量等与另外五种天气共用。画质越高，倒悬的树越多、树根越细致。

`saves/<世界名>/serverconfig/veilborne-server.toml`：

- `naturalVerdantDream`：自然出现（昼夜皆可）。
- `verdantDreamDurationSeconds`：持续时间，默认 780 秒，范围 120–3600。
- `dreamVisitors`：花路与梦树旁的回眸、游荡的梦种与梦藤围场、失路叶鱼。

多人游玩时，服务器与每名玩家需要安装相同版本的模组。

## 世界规则

- 不破坏建筑，不放下天气方块，不碰作物：游荡的梦种只绕着作物游，不收割、不改种、不催熟。
- 叶鱼、梦种和巨鹿都不会伤害任何东西，也不会被伤害；巨鹿的脚步不会踩坏方块。
- 只有你亲手种下的梦种会长出真实的梦树，而且不会自己蔓延；梦树叶不会枯萎掉落。
- 花灯的小鱼群只是景象，不会离开它。
- 处于天气区域之外、或把客户端效果关掉时，天色与声音会平滑恢复。

## 1.7.0：留下的东西与完整度

- **梦树心**：梦种长成的梦树，树干最底下一格是梦树心。树冠有叶时，周围八格（饱满梦种的树十二格）的作物、树苗、浆果、甘蔗、竹子等约两倍速生长，幼崽长大、繁殖冷却快一倍，繁殖时常生双胞胎，还会偶尔落下梦叶。1.7.0 之前长成的梦树没有心。
- **梦叶**（梦树叶）：所有动物都吃（右键大的动物进入求偶状态，右键幼崽长大一些），放进堆肥桶 85% 成层。
- **完整度**：巨鹿走过、沿花路走到梦树下、巨鹿回眸（2 点）、把梦种引到泥土上、带回失路的叶鱼、走完梦藤围场（隐藏一项）。三星（5 点）余赠一颗饱满梦种和八片梦树叶。

完整的说明（完整度的每一项、余赠、险路的细节）见 `余泽与完整度_使用说明.md`。
