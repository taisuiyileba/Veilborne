# 天幕异闻 · 镜天巡礼 1.3

适用：Minecraft 1.21.1 / NeoForge 21.1.248。模组文件为 `mods/veilborne-1.21.1-neoforge-1.7.1.jar`，与星海倒灌、月骸花潮、绯线缝世是同一个模组，不需要其他前置。

## 马上体验

在允许作弊或具有管理员权限的世界中，站在主世界露天处输入：

```text
/veilborne mirrorsky start
```

完整演出十三分钟，白天黑夜都可以。想直接看某个阶段，用百分比跳转：

```text
/veilborne mirrorsky stage 30    倒影：抬头看倒悬的大地，多出来的塔与门
/veilborne mirrorsky stage 45    来客：迟到的旅人、三面镜框、镜兽的裂片
/veilborne mirrorsky stage 63    巡礼：巨人在你身旁停下，转身看你
/veilborne mirrorsky stage 80    裂镜：裂纹像极慢的闪电爬满天穹
/veilborne mirrorsky stage 93    归天：镜片一块块落下
```

其他命令：

```text
/veilborne mirrorsky status
/veilborne mirrorsky start 180
/veilborne mirrorsky stop
```

四种天幕异象同一时间只会有一个。开始一个时，正在进行的另一个会立即平稳结束。

## 一场镜天会发生什么

| 时间 | 阶段 | 你会看到 |
| --- | --- | --- |
| 0:00–1:00 | 镜兆 | 静水照出一片不属于此刻的晴空；有些脚步声晚一拍才回来 |
| 1:00–3:00 | 覆镜 | 银从天顶像霜一样铺下，云散去，竖直的镜片在半空慢慢转动 |
| 3:00–7:00 | 倒影 | 天空成了一面不太平整的大镜子，映出你周围倒悬的真实大地；镜里多出一座塔、一扇门 |
| 7:00–9:30 | 巡礼 | 一位倒悬的巨人从镜中大地远处走来，在你身旁停下，转身，举起铜镜看你 |
| 9:30–11:30 | 裂镜 | 裂纹从两处慢慢爬开，一道主裂贯穿整片天穹，分支的尖端闪着金光 |
| 11:30–13:00 | 归天 | 镜片从低处开始一块块脱落，化作光雨；真正的天空从缺口里回来 |

白天的镜子是浅银色；夜里是深青色，倒影里的灯火和窗户是金色的。

## 在镜天之下

- **倒影：** 镜里是你周围真实的地形、房子、水面和灯火，只是倒过来，按实时的方块重新绘制。你放下或拆掉的方块，镜里会晚几秒才跟着变。
- **镜面：** 镜子由许多略微倾斜的大镜片拼成，接缝处倒影会错开一点；一道缓慢的光带扫过时，接缝会闪一下。
- **镜片：** 半空中有几片竖直的镜子缓慢转动，透过它们看见的是另一个时刻、另一种色温下的景物。
- **残影与回声：** 你跑动时身后会拖出一两个很淡的残影；有些脚步声晚半拍返回。这些都只在本地客户端绘制，不影响你的实际位置和操作，可以在设置里关掉。
- **室内：** 屋里看不到镜子，只有门窗处透进一点银光。
- **动物：** 附近的原版动物会停下来，抬头看自己的倒影；巡礼时它们都望着巨人。
- **声音：** 天上有玻璃般的低鸣。镜兆时一声倒放的钟，覆镜时霜花蔓延，裂镜时是缓慢的玻璃呻吟；巡礼者每一步都很远很重，锡杖上的环随之作响，偶尔能听见一段低沉的巡礼歌。

## 来客与奇遇

### 多出来的门

倒影阶段，镜里你附近的某面墙上会多出一扇地上没有的门（优先选你自己建的房子，其次是山壁；四周都没有墙时，是空地上一扇独立的门框）。镜中那个位置会有一点金光。

1. 手持**观测棱镜**按住使用，举到眼前。棱镜里还能看见镜中才有的那座塔。
2. 在二十来格内对准那面墙，保持约一秒。现实中的墙上会浮出一道光框，门就开了。
3. 右键光框（独立门框则直接走进去），进入镜廊。

门在异象接近尾声、镜子开始碎之前关闭。

### 镜廊

一条短小、安静的长廊，一侧是整面的镜墙。镜里的你总是慢一拍，而且镜里的石台上放着一件现实这边没有的东西。

- 走到石台前的金色地砖上站一会儿，镜中的你会替你把它取来：获得**回响镜**和两份镜砂。
- 从入口处的门右键即可回去，回到你进门的地方。
- 镜廊里不会受到伤害，也不能破坏或放置方块。
- 下列情况都会把你安全送回原处：停留超过约三分钟（提前有提示）、掉出走廊、掉线重登、镜子开始碎。原处被堵住时，会找一处附近的安全地点，找不到则回到世界出生点。

### 迟到的旅人

你走过一段路之后，一个淡色的"你"会在不远处把那几秒重走一遍。它走到你当时停下的地方还会再多走几步，走向附近的门、镜框或裂片，然后停下来指着那里。走到它身边会得到观测记录。它只重演走路，不重演攻击、开箱或丢东西。

### 错位路标

有时你附近会立起三面带底座的青铜镜框，彼此围成一个小圈，站在中间三面都照得见你：

- 一面照着此刻；
- 一面里的你慢了半拍；
- 一面照的是别处：暖色的傍晚，你身后还站着一个人。

用观测棱镜对准你认为照着此刻的那面，保持一秒多。认对了，另外两面碎成无害的光片，并掉下镜砂；认错了，那面镜子只会颤一下，提示你哪里不对，没有任何惩罚，可以再试。

### 镜兽

有时附近低处会立着一两块开裂的镜片，上面爬着玻璃质的小兽。

- 走到裂片五格以内，它先发出高频鸣音，地上亮起一圈碎光。这是预警。
- 预警持续两秒。这期间退开，它就平息下来，什么也不会发生。
- 留在原地，裂片会炸开，放出三只镜兽。它们很脆（3 颗心），打碎后掉镜砂；半分钟后或镜子碎尽时会自己裂开消失。
- 创造与旁观模式不会触发；和平难度下不会出现镜兽。

### 巡礼者

巡礼阶段，一位穿青金长袍、戴斗笠的巨人在镜中大地上从远处走来。它脚踩镜中的地面，所以在天上是倒悬的：斗笠垂向地平线，长袍一直连到天上。它手持挂着纸灯的锡杖，脸藏在斗笠下的珠帘后面。

- 它的路线穿过巡礼开始时有人站着的地方。它走近时，真实地面上会扫过一片暗影，每一步都在镜面上荡开一圈涟漪。
- 走到你身旁约七十格处，它停下，转身面向你，举起铜镜。铜镜映下的一道光落在你站的地方。站够一会儿，它才继续往前走。
- 在露天看着它走近，会得到观测记录。

另有一条隐藏记录，与它停下时的那一眼有关。

### 最后一片

镜子碎尽时，会有一片带着光尾落到你附近：**天镜残片**。

## 收获

| 物品 | 来源 | 作用 |
| --- | --- | --- |
| 镜砂 | 认对镜框、打碎镜兽、走完镜廊 | 制作材料 |
| 观测棱镜 | 合成 | 按住使用举到眼前：揭开多出来的门，认出照着此刻的镜框，看见镜中才有的塔 |
| 回响镜 | 镜廊石台 / 合成 | 使用：地上显出你最近半分钟走过的路和淡淡的身影；冷却 30 秒 |
| 镜灯 | 合成 | 光源（亮度 13）。火苗前的铜镜把光只往一个方向送：放下时光朝向你，脚前留一片光池 |

| 透光镜 | 合成 | 在主世界露天举起，消耗它唤来一场完整的镜天巡礼；已有异象或头顶有遮挡时不会消耗 |

## 观测手记

第一次见到镜天时会自动获得手记（已有手记则不重复发放），书页顶端多出一条银色书签。点击书签或按 **Tab** 在已发现的章节之间切换。镜天巡礼一章同样有四个跨页：异象纪要与实时时间轴、来客与奇遇、工艺、观测记录与守则。

六条公开的观测记录：

1. 天空镀上了银。
2. 巡礼者从镜中走过。
3. 多出来的那扇门。
4. 镜中的你替你取来了它（镜廊）。
5. 照出此刻的那面镜子。
6. 跟上了迟到的旅人。

另有一条隐藏记录。

## 自然出现

镜天巡礼白天黑夜都可能开始，与另外三种天气共用平静期：一场异象结束后，要再过几个游戏日才会有下一场。几种天气都开启时，此刻能开始的那几种机会均等（月骸花潮只在入夜后参与）。每场会随机带上错位路标或镜兽之一或两者。

## 设置

`config/veilborne-client.toml`：

- `mirrorReflections`：天空里绘制你周围真实的倒悬大地。关掉后只显示远处的绘制倒影，更省性能。
- `mirrorAfterimages`：跑动时身后的残影。
- `mirrorEchoes`：晚一拍返回的脚步声。
- 画质、天空、天光染色、效果亮度、音量等与另外三种天气共用。画质越高，倒影覆盖的范围越大。

`saves/<世界名>/serverconfig/veilborne-server.toml`：

- `naturalMirrorSky`：自然出现。
- `mirrorSkyDurationSeconds`：持续时间，默认 780 秒，范围 120–3600。
- `mirrorVisitors`：迟到的旅人与错位路标。
- `mirrorBeasts`：镜兽与裂片。
- `mirrorGallery`：多出来的门后的镜廊。关掉后门仍会显现，但推不开。

多人游玩时，服务器与每名玩家需要安装相同版本的模组。镜廊是一个很小的独立维度，第一次进入存档时 NeoForge 可能提示"实验性设置"，确认即可，之后不再提示。

## 世界规则

- 不破坏建筑，不清空容器，不强行把任何人带走；镜廊只有自己推门才进得去，出口永远通回原处。
- 门只"显现"在墙上，不改动那面墙的方块。
- 镜框、裂片与最后一片的位置都经过安全检查，不会出现在岩浆、水中、虚空或建筑内部。
- 离开天气区域，天色与声音会平滑恢复。

## 1.7.0：留下的东西与完整度

- **镜中之塔的地基**：倒影出现后，镜里多出一座塔。举起观测棱镜对准塔在地面上的位置一秒多，塔影伸进地下；从正中往下挖四五格是一间旧石室和一只宝箱（必有一本附魔书）。坐标记在手记里，天气结束后也能回去挖。
- **两波镜兽（险路）**：让裂片炸开并打完第一波，人还留在附近会来第二波；两波打完留下**裂镜之心**，捏碎后三十二格内的箱子、刷怪笼、可疑的沙子等透过地面显形半分钟。
- 棱镜的判定顺序：多出来的门、近处的镜框，然后才是远处的塔。
- **完整度**：巡礼者走过、找到门、取来回响镜、认出此刻的镜子、跟上旅人、找到塔基，另有险路（2 点）与隐藏一项。三星（5 点）余赠六份镜砂和一面透光镜。

完整的说明（完整度的每一项、余赠、险路的细节）见 `余泽与完整度_使用说明.md`。
