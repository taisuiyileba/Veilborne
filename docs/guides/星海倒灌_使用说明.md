# 天幕异闻 · 星海倒灌 1.2

适用：Minecraft 1.21.1 / NeoForge 21.1.248。模组文件为 `mods/veilborne-1.21.1-neoforge-1.7.1.jar`，源码位于 `Veilborne` 文件夹。无需其他前置模组。

之后陆续新增了月骸花潮（1.2）、镜天巡礼（1.3）与绯线缝世（1.4），说明见各自的使用说明。四种异象同一时间只会出现一个，并共用平静期。

## 马上体验

安装后重启游戏，进入主世界。在允许作弊或具有管理员权限的世界中输入：

```text
/veilborne starfall start
```

完整演出约十四分钟。想直接观看星鲸，可输入：

```text
/veilborne starfall stage 62
```

站在露天位置仰望天空。星鲸沿一条缓弧从天气中心附近的天幕中游过，在中段离头顶最近；它用尾鳍上下拍水，背上驮着一艘旧沉船，两侧垂着挂星珠的海草链。

其他命令：

```text
/veilborne starfall status
/veilborne starfall start 120
/veilborne starfall stop
```

`start 120` 是两分钟的紧凑体验；`stop` 结束天气并安全送离船上乘客。

## 一场星海会发生什么

| 阶段 | 你会看到 |
| --- | --- |
| 前兆 | 河面、湖面的水滴拖着短尾迹向上飘；陆地浮起零星星屑，远处一声鲸鸣 |
| 开幕 | 云层变淡、升高并散去，倒悬的星海从天顶张开，地平线亮起一圈海雾 |
| 潮盛 | 光瀑从星海垂落，下半段碎成星屑；漂流瓶抵岸，无海之舟经过，浮潮涡亮起 |
| 鲸游 | 星鲸越过天幕，它下方的地面随之泛起一片移动的蓝光 |
| 余辉 | 一道光柱标出落点，鲸鳞拖着金色尾迹坠下 |
| 退潮 | 星海从边缘卷回天上，潮声远去 |

## 生存模式

首次自然异象约在一个游戏日后寻找触发机会，需要有玩家处于主世界露天。之后每场结束（包括月骸花潮）休息 3–6 个游戏日。

- **观测手记：** 首次见到星海时获得。右键展开，Tab 在星海与月骸两章之间切换。每章共四个跨页：扉页与此刻的天幕进度、来客与奇遇、配方、观测记录。用两侧箭头、鼠标滚轮或方向键翻页，悬停图标可查看物品说明，Esc 关闭。未完成的观测只显示一句线索。
- **漂流瓶：** 潮盛时出现在你附近的岸上，瓶身微微发光。右键开启，获得可放在家中的星潮瓶。
- **无海之舟：** 一艘半透明的小舢板在离地一两格处漂过，船头挑着一盏纸灯笼，船尾坐着戴斗笠、披蓑衣的钓星老翁。右键登舟，坐在船头与他同行；潜行下船。船离开时会先把你安全放下，再慢慢化为雾气。
- **浮潮涡：** 地面先亮起一圈缓慢转动的金色符环，这是预告；数秒后变成青色并升起光柱，圈内的玩家会缓慢浮起，结束后带缓落保护。不想参与就退到圈外。
- **鲸鳞：** 星鲸游过后，跟随落地的光柱寻找星鲸鳞与星螺。
- **鲸纱披风：** 右键使用，提供 30 秒缓落，冷却 60 秒。
- **星螺：** 右键可以再次听见鲸鸣。
- **瓶中星海：** 放置星潮瓶，得到黄铜底座上的软木塞玻璃罐，罐里的小片夜海会动、会发光，并飘出细小星屑。

普通天气默认不会破坏建筑或清空容器。睡眠、昼夜变化不会直接跳过异象，离开区域会平滑恢复正常环境。

## 合成

手记的"工艺"页直接显示游戏内的实际配方；整合包修改配方后也会同步。

**观测手记**：上方一枚紫水晶碎片，下方一本书。

**鲸纱披风**：

```text
鲸鳞   空     鲸鳞
幻翼膜 白色羊毛 幻翼膜
空     幻翼膜   空
```

**听潮信标**：

```text
空       紫水晶碎片 空
末影珍珠 鹦鹉螺壳   末影珍珠
空       金锭       空
```

在主世界露天使用信标，会消耗它并唤来一场星海；已有异象或条件不符时不消耗。JEI 中也能查看配方。

## 设置

- `config/veilborne-client.toml`：画质（0 轻量 / 1 均衡 / 2 电影）、天空、地面潮光、天光染色、效果亮度、声景和音量。轻量档会降低星鲸网格与粒子数量，星鲸、玩法与危险预告全部保留。
- `saves/<世界名>/serverconfig/veilborne-server.toml`：自然触发、间隔、持续时间、区域半径、浮潮互动和首次赠送手记。

默认天气半径 320 格。视距很短（2–4 区块）时，星鲸会等比例拉近绘制，仍能完整看到。

多人游玩时，服务器和每名玩家都需安装相同版本的模组。

## 1.1 更新内容

- **无海之舟重做：** 原版风格的方块模型与贴图，船长约 2.5 格、宽约 1 格，与原版船同比例。蓑笠翁坐在船尾，钓线末端挂着会"咬钩"的星星，船头有纸灯笼。船身半透明，船缝发光，船底滴水。船头始终沿航线方向，乘客座位随船身转动，离场时会淡出。
- **星鲸重做：** 按座头鲸比例建模的平滑网格，用尾鳍上下拍水。皮肤有星点背纹、腹部褶沟、藤壶与抓痕。专用着色器提供来自星海的光照、背部焦散、边缘光晕与距离海雾。它在世界中绘制，山脊可以遮挡它。背上的沉船有完整船壳、破损露出的肋骨、帆、索具与灯笼。
- **天空：** 开幕时原版云层逐渐淡出，不再以黑色方块挡在星海前面。光瀑改为柔和的流动光幕，并碎成星屑；地平线加了海雾光带。浮潮涡改为转动的符环加光柱，鲸鳞坠落有光柱与尾迹。
- **粒子：** 星屑改为叠加发光并会闪烁，新增前兆阶段从水面升起的逆流水滴。
- **道具与方块：** 全部重绘为 16×16 像素风格，漂流瓶与星潮瓶不再共用贴图；星潮瓶、星鲸鳞、听潮信标带动画。瓶中星海改为可见玻璃罐，内部的小海会动并自发光。
- **观测手记：** 重做为四个跨页的星图笔记，含实时阶段时间轴、图标、配方和线索式观测记录；中文排版不以标点开头。

## 1.7.0：留下的东西与完整度

- **远航**：登上无海之舟后，面向想去的方向按住前进键约一秒半，老翁把你送到那个方向最近的沉船、海底废墟、海底神殿或远古城市上空，并给一枚**归岸贝**（右键回到上船处，一次性）。无海之舟现在停留约两分钟。
- **将熄的鲸鳞**：光柱落地处散落五枚鲸鳞，每一枚在四十五秒内熄灭，要赶在那之前捡起。星螺不会熄。
- **星潮池**：鳞片落下的地方留下三天的星潮。四十格内的水里钓鱼，常会额外钓上星海里的东西，其中有**卷着海图的漂流瓶**（打开得到一张原版宝藏图）。
- **完整度**：见证古鲸、登船、随浮潮升起、打开漂流瓶、接住三枚鲸鳞（2 点）、一枚也没熄、随老翁远航。三星（6 点）余赠两枚星鲸鳞和一只海图漂流瓶。
- 手记第九、十页记着星潮池与远航到过的地方的坐标。

完整的说明（完整度的每一项、余赠、险路的细节）见 `余泽与完整度_使用说明.md`。
