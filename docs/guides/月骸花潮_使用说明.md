# 天幕异闻 · 月骸花潮 1.2

适用：Minecraft 1.21.1 / NeoForge 21.1.248。模组文件为 `mods/veilborne-1.21.1-neoforge-1.7.1.jar`，与星海倒灌、镜天巡礼、绯线缝世是同一个模组，不需要其他前置。

## 马上体验

在允许作弊或具有管理员权限的世界中，站在主世界露天处输入：

```text
/veilborne moonbloom start
```

完整演出十二分钟。想直接看某个阶段，用百分比跳转：

```text
/veilborne moonbloom stage 30    花潮：花瓣、花影、送月人与小月亮
/veilborne moonbloom stage 62    蜕月：月壳剥落，金色月核露出
/veilborne moonbloom stage 66    三月同天
/veilborne moonbloom stage 80    送月：最后一名送月人放下灯
```

其他命令：

```text
/veilborne moonbloom status
/veilborne moonbloom start 180
/veilborne moonbloom stop
```

月骸花潮与星海倒灌同一时间只会有一个。开始一个时，另一个会立即平稳结束。

## 一场花潮会发生什么

| 时间 | 阶段 | 你会看到 |
| --- | --- | --- |
| 0:00–1:00 | 月晕 | 月亮戴上一圈 22° 光环，云层变淡，天色开始转紫，影子变长 |
| 1:00–3:00 | 裂壳 | 月面的瓷釉一道道裂开，裂缝里渗出金光；第一批瓷片剥落 |
| 3:00–7:00 | 花潮 | 瓷片落进大气变成花瓣，落地处绽开银白花影；送月人经过，林间落下小月亮 |
| 7:00–9:00 | 蜕月 | 月壳大片剥落，露出温暖的金色月核；随后天上出现三个月亮 |
| 9:00–10:30 | 送月 | 送月人把月壳举向天空，最后一名送月人在路边留下一盏银花灯 |
| 10:30–12:00 | 合壳 | 月壳重新合拢，花影从远处一圈圈闭合，天色回到正常 |

白天使用望月铃也能看到完整演出，月亮与天色会淡一些。

## 在花潮中

- **花瓣与花影：** 花瓣从真月那一侧被风吹来，缓慢翻转着飘落。落在地面或水面上会绽开一朵花影；花影沿坡地和小路连成片。走过花影，它会散成光尘。
- **灯火：** 花瓣靠近火把、灯笼、营火时会绕出小螺旋。
- **月影：** 月光下，你和送月人脚下会拖出一道细长的紫色月影，总是背向真月。月影始终贴着你的脚，但它的动作（迈步、转身、下蹲）比你慢半拍，默认 4 tick，即 0.2 秒。这是有意的效果，不是网络延迟：月影完全在本地客户端绘制。不喜欢可以调小或关掉。
- **室内：** 屋里不落花，只在门口和窗边透进一些花光。
- **动物：** 附近的原版动物会停下来，安静地望着月亮。怪物不会因此消失。
- **声音：** 天上有很淡的弦声。花潮里偶尔能听见一段不完整的摇篮曲，每次拼出的顺序都不一样。

## 来客与奇遇

### 送月人

花潮开始后不久，一队无面的披纱身影会从你附近经过：领路人执杖在前，四人抬着一片发光的月壳，最后一人挑着灯。

- 在大约 4–14 格外同行一段路，会得到"与送月人同行"的记录。同行时，地上会显出一条通向他们终点的隐藏花路。
- 走进队列，他们会散成花瓣，过一会儿在前方远处重新汇聚。他们不会攻击，也不会贴脸出现。
- 他们绕开墙壁与屋顶。遇到房屋会在门外停一会儿，然后散开，在房子另一边重新聚起。
- 到达终点后，他们把月壳举向月亮。送月阶段开始时，最后一名送月人会在路边放下一盏银花灯，然后整支队伍淡去。

队伍里总有一个空着的位置。**提着银花灯走近它**，那里会短暂出现一个穿着你的盔甲、拿着你手中物品的轮廓，向你挥手。这条观测记录在发现之前不会出现在手记里。

### 落地的小月亮

花潮中段，附近的林间（没有树林时是一片空地）会亮起一个一两格大的漂浮月体，周围的花瓣反向往上升。

- **月露：** 拿着空玻璃瓶靠近它并右键，接住一瓶月露。每个小月亮给每名玩家最多三瓶。
- **星座：** 它附近的地上有一圈金环。站进金环里看向小月亮，会看到一个只在这个角度连得起来的星座。保持注视两秒，获得观测记录。
- 送月阶段过后，小月亮离去，原地留下一枚月瓷片。

### 三月同天

蜕月之后，月亮分成三个，外观几乎一样。只有一个是真月。线索：

- 只有真月还在往下掉瓷片。
- 花瓣总是从真月那一侧吹来。
- 地上的月影背向真月。
- 银针月仪的指针指向真月。

对准你认定的真月（准星对上月面即可），使用**银针月仪**。选对了，两个倒影会像碎瓷一样剥落，并掉下两枚月瓷片；选错了只会提示"那是一轮倒影"，没有任何惩罚，可以再试。可以辨认的时间约八十秒。

## 观测手记

第一次见到花潮时会自动获得手记（已有手记则不重复发放），书页顶端随之多出一条淡紫色书签。点击书签或按 **Tab** 在"星海倒灌"与"月骸花潮"两章之间切换。月骸花潮一章同样有四个跨页：异象纪要与实时时间轴、来客与奇遇、工艺、观测记录与守则。

五条公开的观测记录：

1. 第一片落地的月瓷：在异象中亲眼看见落下的花瓣。
2. 目送月壳剥落：蜕月时站在露天处仰望。
3. 与送月人同行。
4. 只在一处成立的星座。
5. 辨认真月。

另有一条隐藏记录。

## 自然出现

月骸花潮只在入夜后（游戏时间 12000–18000 之间）开始，与另外三种天气共用平静期：一场异象结束后，要再过 3–6 个游戏日才会有下一场。几种天气都开启时，此刻能开始的那几种机会均等。

## 设置

`config/veilborne-client.toml`：

- `moonShadows`：月影开关。
- `moonShadowLag`：月影动作落后的 tick 数，0–10，默认 4；设为 0 则与你完全同步。
- `moonLullaby`：摇篮曲开关。
- 画质、天空、天光染色、效果亮度、音量等与星海倒灌共用。

`saves/<世界名>/serverconfig/veilborne-server.toml`：

- `naturalMoonBloom`：自然出现。
- `moonBloomDurationSeconds`：持续时间，默认 720 秒，范围 120–3600。
- `moonVisitors`：送月人与小月亮。
- `moonLanterns`：送月人留下实体灯。

多人游玩时，服务器与每名玩家需要安装相同版本的模组。

## 世界规则

- 不破坏建筑，不清空容器，不强行移动任何玩家。
- 送月人不进屋，不爬墙，也不上屋顶。
- 小月亮与留灯的位置都经过安全检查，不会出现在岩浆、虚空或建筑内部。
- 离开天气区域，天色与声音会平滑恢复。

## 1.7.0：留下的东西与完整度

- **月下安地**：银花灯周围二十四格内，黑暗里不再自然生成怪物（刷怪笼、刷怪蛋、袭击不受影响）。旧存档里已放下的银花灯会自己生效。
- **月隐药水**：酿造台里把月露加进粗制的药水（3:00，红石延长到 8:00，可做喷溅、滞留与药箭）。怪物很近才会注意到你，已经在追的离远了会跟丢。
- **越早越好**：三月同天里越早认出真月，残留的月光越多：最早能得到三片月瓷片和两瓶月露，拖到快合月只有一片瓷片。月仪会报出"残留的月光"。
- **完整度**：目送月壳剥落、与送月人同行、接住月露、看见星座、辨认真月、在前一半时间内辨出（隐藏一项）。三星（5 点）余赠两盏银花灯和两瓶月露。

完整的说明（完整度的每一项、余赠、险路的细节）见 `余泽与完整度_使用说明.md`。
