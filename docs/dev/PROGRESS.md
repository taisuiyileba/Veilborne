# 天幕异闻实现与验证

## 1.7.1 动作与建模修正（2026-10-03）

目标：玩家反馈的六个问题——梦种移动卡顿、小仙舟太慢、镜廊镜面偶尔变黑、镜兽尾巴朝前、送月人后排与提灯者的手臂方向，以及建模贴图重叠造成的闪烁。

- [x] 梦种卡顿：服务端移动的普通实体，原版 `Entity.lerpTo` 收到位置包就直接跳过去，两次更新之间停住再一跳。梦种、叶鱼群、镜中旅人改为在客户端按刻滑向服务端位置（`Glide`），梦种每刻同步一次。
- [x] 小仙舟：绕一圈从约 112 秒缩到约 48 秒，最快每秒约 1.8 格（仍比步行慢）。被挡住后每刻最多前进 0.3 格追回航线，并按每一步的落脚处判断屋顶与碰撞；原来是被挡住时原地等、能走时一步跳到航线上，可能穿过墙。
- [x] 镜廊变黑：镜中世界的区块网格在区块光照到达之前就被构建，那部分镜面全黑，且之后不会重建（镜墙背后是黑石）。现在等这个区块和相邻区块的光照就绪后再构建（原版编译区块也这样等）；天空之镜的倒影同样受益。
- [x] 镜兽：模型头朝 +z，渲染却按原版"头朝 −z"转了 180°，所以尾巴在前；头部转向的正负号一并改正。镜片上爬行的镜兽改为沿爬行方向头在前。
- [x] 送月人：模型以 +z 为前，正的 x 转角是手臂向前，原姿势全部写反，所有人的手都伸向身后。前排抬轿人手向后握杆，后排向前握杆；引路人的铃杖与提灯人的灯杆握在身前，灯垂直挂在灯杆弯头下。
- [x] 无声白昼（同一类问题）：提灯、打伞、提鸟笼、拄杖都拿在身后，"仰望黑日"其实是低头，拄杖老人往后仰；空大衣敲门时袖子往身后抬，鞠躬是往后仰。全部改正。
- [x] 贴图重叠：`tools/art/boxmodel.py` 导出时自动找出共面且重叠的面，把其中一个面向外推 0.2 像素（只动这一个面，方块尺寸与贴图不变），直到没有两个面在同一平面上；`exclusive`（不同时显示的帽子、道具）与 `posed`（渲染时总会转开的手臂、道具）不参与比较。六个实体模型共 0 处残留；方块模型里鹿角枝两根交叉的枝错开 0.3 像素；梦鹿鹿角小屋的窗离墙从 2 厘米加到 12 厘米。
- [x] 验证：88 项 GameTest（新增 `skiffCatchesUpInsteadOfLeaping`）；`.dev/art/coplanar_audit.py` 共面审计为 0；`.dev/art/bearer_pose.py` 侧视图核对手臂；美术场景新增 `skiff_speed`、`dream_seed_motion`、`mirror_gallery_walk_a/b/c`、`mirror_beast_walk`（日志行 `VEILBORNE_MOTION`、`VEILBORNE_GALLERY`、`VEILBORNE_BEAST`）；星海、梦潮自然流程回归。

- [x] 线灵减弱：每下半颗心、间隔更长，口袋收成残丝时随之散去（此前完整流程中 QA 玩家在口袋收成后被啄死）。完整流程 42 项、GameTest 47 项在最终源码上重新通过；1.4.0 重新构建并安装。
