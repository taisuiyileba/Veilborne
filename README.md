# 天幕异闻 · Veilborne

目标平台：Minecraft 1.21.1，NeoForge 21.1.248，Java 21。独立模组，无额外运行依赖。开源协议：[MIT License](LICENSE)。

当前版本 **1.0.0**（开发历程 1.0–1.7.1 整合首发），包含六种天幕异象：**星海倒灌**、**月骸花潮**、**镜天巡礼**、**绯线缝世**、**无声白昼**与**苍翠梦潮**，以及配套的余泽体系与一至三星完整度结算（见下文"天气留下的东西"与 [余泽与完整度_使用说明.md](docs/guides/余泽与完整度_使用说明.md)）。发布文件位于 `build/libs/veilborne-1.21.1-neoforge-1.0.0.jar`。

## 星海倒灌

- 默认在主世界自然出现。第一次需要约一个游戏日，之后按上面的共同平静期出现。
- 一次完整异象持续十四分钟，半径默认 320 格。依次发生：水滴逆流、星海展开、来客抵岸、古鲸经过、光鳞降落、星海退去。
- 首次进入天气区域时获得观测手记。右键展开，四个跨页用箭头、滚轮或方向键翻页，Tab 切换章节，Esc 关闭。
- 在工作台用紫水晶碎片置于书本上方，也可以制作观测手记。
- 漂流瓶开启后获得星潮瓶，可放在家中发光并产生微型星屑。
- 右键幽舟登船，坐在船头与钓星的蓑笠翁同行，潜行离开；**按住前进键**，老翁朝你看着的方向远航，把你放到那边最近的沉船、海底废墟、海底神殿或远古城市上空，并给一枚归岸贝回到上船处。浮潮涡先出现金色预告符环，数秒后转青并托起环内的玩家，最后以缓落结束。
- 古鲸经过后，光柱落地处散落五枚鲸鳞，四十五秒内逐一熄灭，要赶在那之前捡起；星螺留在中间。落点留下三天的**星潮池**：四十格内的水里钓鱼常会多钓上星海之物，包括卷着海图（原版宝藏图）的漂流瓶。鲸纱披风提供 30 秒缓落，60 秒冷却。
- 听潮信标可以主动唤来完整异象；需要主世界露天且当前无异象。配方为：紫水晶碎片在上，两颗末影珍珠夹鹦鹉螺壳，金锭在下。

## 月骸花潮

- 只在入夜后（游戏时间 12000–18000）自然开始，完整持续十二分钟。依次为月晕、裂壳、花潮、蜕月（三月同天）、送月、合壳。
- 月亮的瓷壳一道道裂开，裂缝透出金光；瓷片落进大气变成花瓣，落地绽开银白花影，沿坡地和小路连成片。屋内只在门窗附近透进花光。
- 月光下玩家与送月人脚下拖着一道细长月影，背向真月；月影贴着脚，动作慢半拍（可调）。
- **送月人**：抬着月壳的无面披纱队伍沿一条确定的路经过，不爬墙、不进屋；保持距离同行会显出隐藏花路，走进队列则散成花瓣、在前方重新汇聚。送月时最后一人在路边留下一盏银花灯。
- **落地的小月亮**：林间的一两格漂浮月体。空瓶右键接月露（每人每个小月亮三瓶），站进金环看向它可见只在该角度成立的星座。
- **三月同天**：真月是唯一还在掉瓷片的那个，花瓣从它那边吹来，月影背向它，银针月仪指向它。对准真月使用月仪，倒影碎去；选错没有惩罚。辨得越早，留下的月瓷片和月露越多。
- **月下安地**：银花灯周围二十四格内不自然生成怪物。**月隐药水**：粗制的药水加月露（红石延长），怪物很近才会注意到你。
- 收获：月露（夜视）、月瓷片、月纱（诱饵幻影 + 5 秒隐身）、银针月仪、银花灯（装饰光源）、望月铃（唤来一场花潮）。
- **空位**：队伍里始终空着一个位置。提着银花灯走近，那里会短暂出现穿着你的盔甲、拿着你手中物品的轮廓，向你挥手。它只使用游戏内模型。

## 镜天巡礼

- 白天黑夜都可能自然开始，完整持续十三分钟。依次为镜兆、覆镜、倒影、巡礼、裂镜、归天。
- 天空变成一面不太平整的大镜子，映出你周围**真实的**倒悬大地：附近区块按实际方块重新构建网格、反射绘制，远处退为绘制远景。镜里多出一座塔、一扇门；白天是浅银色，夜里是深青色，倒影里的灯火是金色。裂纹像极慢的闪电，主裂贯穿天穹，最后镜片从低处开始一块块落下。
- 镜兆时静水映出天气过后的晴空；有些脚步声晚一拍返回，跑动时身后有很淡的残影（仅客户端，可关）。空中有竖直镜片转动，里面是另一个时刻的暖色景物。
- **多出来的门**：镜里某面墙（优先玩家建筑）多出一扇门。用观测棱镜对准现实中的那面墙约一秒，光框显现，右键进入**镜廊**：一处无伤、不可改动的小型预制空间，镜墙里的你慢一拍；站上石台前的金砖，镜中的你替你取来回响镜。退出、超时、掉落、掉线重登、天气结束都会回到入口。
- **迟到的旅人**：一个淡色的你在不远处重走你几秒前走过的路，多走几步，指向附近的奇遇。
- **错位路标**：三面青铜镜框，一面照着此刻，一面慢半拍，一面照着别处（你身后多站着一个人）。用棱镜认出照着此刻的那面；认错没有惩罚。
- **镜兽**：低处开裂的镜片上爬着玻璃小兽。靠近先有鸣音与地面碎光预警，两秒内退开就平息，留下来才会炸开。打完第一波仍留在原地会有第二波；两波打完留下裂镜之心（捏碎后附近的箱子、刷怪笼透过地面显形）。
- **镜中之塔的地基**：用观测棱镜对准塔在地上的位置一秒多，塔影伸进地下；往下挖是一间有宝箱的旧石室。
- **巡礼者**：倒悬的青金长袍巨人从镜中大地远处走来，地面扫过它的暗影，每一步在镜面荡开涟漪；在你身旁七十来格停下，转身举起铜镜，一道光落在你身上。
- 收获：镜砂、观测棱镜、回响镜（显示最近半分钟走过的路）、镜灯（定向光源）、天镜残片（挂墙装饰）、透光镜（唤来一场镜天）。

## 绯线缝世

- 白天黑夜都可能自然开始，完整持续十三分钟。依次为引线、裂天、落针、缝世、收线、余线。
- 天空变成一整匹垂挂的绯红丝绸，从中间撕开一道固定在大地上空的伤口，边缘烧着金红的火，缝里是没有星星的黑。一根比山还长的金针（金身嵌着缠绕的绯线）从缝的另一侧穿出，每一针都真的穿过两侧的针眼：从背面出、在前面拉过、再回背面，十三针把伤口一段段拉紧；每穿一次，地平线跑过一道细光，远处织机声随后才到。
- **落针区**：金针三次落到地上。地面先亮起宽阔的符线、向心的尘屑与越收越紧的声音，六秒后一束光先落、针再落下；走出圈外得到记录，留在圈里被击倒抛出（带系缚结或站在调律锚旁只受伤不被抛动）。建筑不受损。
- **缝世**：金针落进你附近的大地，从地底穿过，在两百格外破土而出，把世界缝到天上；看不见的手的影子（皮影戏一般，被天幕后的光衬出来）掠过天幕与大地，把线拉紧。拉线时露天的人被轻轻牵向缝地的那条线，每个活物头顶都连着一根通到天上的线，世界叠出过去几秒的胶片残影（仅客户端，可关）。
- **走针者**：黄铜六足之物沿第一针的红线爬下，收拢线头，坐在线脚下打结。碰它的线结会散成三个线头，抢在它之前接住就得到时缝残丝。
- **未缝合的口袋**：金针离开后留下一小块风吹不进的地方，漂着旧物的幻影。在里面放下调律锚，旧物聚拢成时缝残丝，同时惊醒三只线灵，直到口袋收成残丝才散去。
- 岩壁与树干上会裂开片刻的金色接缝，被一粒火花缝上后消退；高处垂下红线，室内梁下有细线低振。最后缝线冷成金线、化作星带，一小片缀着星星的天衣落在身边。
- **缝在一起的灯**：收线时两处落针点各留一盏相连的织天灯，空手右键一盏就被线牵到另一盏；拿绯线先后点两盏可以自己缝（每六十四格一根绯线）。拉线前可以站在线上护线，也可以用剪刀在落针点剪断它（没有那对灯，但留下一地绯线）。带系缚结站在落针圈正中能接到针芯（伤得更重），它让缝线只用一根线、还能跨维度。
- 收获：绯线、时缝残丝、调律锚（稳定锚点）、系缚结（不被天气位移）、织天灯（彼此之间连起发光红线）、天衣残片（挂墙装饰）、天衣针（唤来一场缝世）。

## 无声白昼

- 白天黑夜都可能自然开始，完整持续十二分钟。依次为失声、褪色、黑日、蚀、迟雷、复声。
- 声音一层层退去：音乐、风与洞穴、动物、方块（闷住而不是消失），最后是自己的脚步；本模组的声音、敌对生物、受伤声和字幕始终保留。云减速停住，尘埃、落叶和水珠停在半空。
- 灰色像潮水一样从视野边缘漫到脚下，世界被提亮成浅灰，只有灯火旁留下旧照片般的暖黄；天空被一幅冻住的苍白正午盖住，太阳（夜里是月亮）成了没有光晕的纸白圆盘。
- 一颗不发光的黑日从北方升起，周围的天空像透镜一样弯曲；世界的颜色从四周地平线化作细带流进它。它盖住白日时天不暗反白，爱因斯坦环一闪，黑色日冕张开，大地被照得更白、动物站住仰头。随后它沉回北方，颜色细带倒流；地平线上立起一道白线，三十四秒后雷声才到。最后一只鸟先唱起来，颜色从你身边向外回来，天空最后。
- **举灯**：手持火把、灯笼之类发光的东西对空处使用，便是你的声音。**无声行列**（五个旧时代旅人，嘴在动却没有声音，蚀的时候一齐停下仰望）与**敲门的空位**（门外一件没有人的长外套，轻敲三下）都会回应；外套鞠躬留下白昼蜡，从帽子开始被擦去。
- **唯一的声音**：远处一只铃每响一次，就有一圈颜色穿过灰色的大地；走到它跟前，周围恢复声音与颜色成为有声岛，合上时铃落下成为空响铃。褪色时身边还悬着一根松鸦的蓝羽，第一只鸟叫了才落下。
- **无声提灯**拿在手里时，幽匿感测体、尖啸体、监守者都听不见你；**静烛**六格内吞掉一切振动。在寂静里故意敲钟、奏乐、吹角，会有监守者从地下爬出来；撑到鸟叫有回响碎片。
- 收获：白昼蜡、空响铃（记下一场异象的声音再放出来）、静烛（周围永远安静一点、灰一点）、无声提灯（照得更远，照出行列不留下的脚印）、罩中羽（玻璃罩里的蓝羽）、停摆钟（唤来一场无声白昼）。

## 苍翠梦潮

- 白天黑夜都可能自然开始，完整持续十三分钟。依次为绒云、垂根、叶海、鹿行、落种、归云。
- 云变软、泛绿，树根从云里垂下来，最长的一直伸到山顶；倒悬的森林从天顶一棵树一棵树地长满整片天。从下面看，是一棵棵树冠：边缘被逆光照成绿金，树与树之间留着缝，缝里是更深处的林子。叶影在地面和外墙上流动，叶鱼成群游过，俯冲到地面化成花粉，地上亮起层层花纹。夜里最薄的叶子和树根里的脉络亮起荧光。
- 附近长出一棵发光的梦树，发光的花瓣沿能走的地面排成一条路通到树下。一条树根铺成的路垂到地上，**托林巨鹿**沿着它走来：身体几乎透明，像光凝成的鹿形，鹿角上长着一整片小树林，林中有灯和小屋；每一步落下，地上开出一圈花影。它在梦树旁停下，**低头看一眼安静等在树下的人**，从鹿角间落下一颗梦种。
- **梦藤围场**：碰一碰绕着作物游动的梦种，藤影围着你长出一圈，在它合拢前追上五道光换一颗饱满梦种；随时可以从出口走开。**失路叶鱼**：困在窗边的一小群金色叶鱼，拿着花或花灯把它们引到露天，它们汇成一条金色大鱼游回天上，落下金叶。
- 每棵树在自己的时候转成蜜金色、落叶，露出树枝的剪影；梦种从天上降下，蹲下或拿着花靠近就跟着你走，引到露天的泥土上会发芽。落进巨鹿的蹄印里，也许会不一样。最后鹿角枝落下，树根收回云里。
- 梦种种出的梦树底部有一颗**梦树心**：树冠有叶时，周围作物约两倍速生长，幼崽长大和繁殖冷却加倍，繁殖时常有双胞胎。**梦叶**所有动物都吃，也能堆肥。
- 收获：梦种与饱满梦种（种出不会蔓延的装饰梦树）、金叶、鹿角枝（墙上的小树林）、花灯（有一小群叶鱼绕着游）、漂叶坠（有限次数的缓落）、鹿鸣笛（唤来一场苍翠梦潮）。

## 天气留下的东西（1.7.0）

| 天气 | 对应的需求 | 留下的东西 | 可选的险路 |
| --- | --- | --- | --- |
| 星海倒灌 | 探索 | 远航与归岸贝；三天的星潮池（额外渔获、海图漂流瓶） | — |
| 月骸花潮 | 夜晚与怪物 | 银花灯周围不刷怪；月隐药水 | — |
| 镜天巡礼 | 寻宝 | 镜中之塔下的宝箱石室 | 两波镜兽 → 裂镜之心 |
| 绯线缝世 | 远距离交通 | 一对相连的织天灯；自己用绯线缝传送网 | 落针圈正中 → 针芯（跨维度） |
| 无声白昼 | 古城与潜行 | 无声提灯与静烛让幽匿方块、监守者听不见 | 在寂静里出声 → 监守者 → 回响碎片 |
| 苍翠梦潮 | 农业与牧场 | 梦树心加速作物与繁殖、双胞胎；梦叶喂养与堆肥 | — |

每场结束时按做到的事结算**完整度**（一到三星，不走险路也能三星），二星、三星各有余赠（例如月骸三星给两盏银花灯和两瓶月露、缝世三星给一盏织天灯）。观测手记每章新增第五个跨页：左页是余泽和"你的标记"（星潮池、远航到过的地方、塔基宝箱、织天灯两端的坐标），右页是这一场或上一场的完整度、最好成绩和每一项的完成情况。完整说明见 [docs/guides/余泽与完整度_使用说明.md](docs/guides/余泽与完整度_使用说明.md)。

## 管理员与创作预览命令

需要作弊权限或服务器管理员权限：

```text
/veilborne starfall start | start 120 | stage 62 | status | stop
/veilborne moonbloom start | start 180 | stage 66 | status | stop
/veilborne mirrorsky start | start 180 | stage 63 | status | stop
/veilborne scarletseam start | start 180 | stage 54 | status | stop
/veilborne silentday start | start 300 | stage 55 | status | stop
/veilborne dreamtide start | start 300 | stage 56 | status | stop
```

`start` 默认完整时长（星海十四分钟、花潮与白昼十二分钟、镜天、缝世与梦潮十三分钟）；数字是持续秒数。`stage` 跳到指定百分比，适合截图和调试。它不会回收已获得的掉落或清除遭遇执行记录。

客户端配置位于 `config/veilborne-client.toml`：画质 0/1/2、天空开关、地面水光、天光染色、特效亮度、声景开关与音量；月影 `moonShadows`、月影动作延迟 `moonShadowLag`（tick，默认 4，0 为同步）与摇篮曲 `moonLullaby`；镜天的真实倒影 `mirrorReflections`、残影 `mirrorAfterimages` 与迟到的脚步声 `mirrorEchoes`；缝世的万物之线 `threadStrings`、胶片残影 `threadMoment` 与岩壁金缝 `threadSeams`；白昼的失声 `hushSilence`、褪色 `hushFade`、悬停的尘埃 `hushMotes` 与远景柔化 `hushBlur`；梦潮的叶影 `dreamDapple`、叶鱼 `dreamLeafFish` 与地上的花纹 `dreamPatterns`。

世界配置位于存档的 `serverconfig/veilborne-server.toml`：

- 星海倒灌：自然触发开关、平静期、持续时间、半径、浮潮涡、首次赠送手记。
- 月骸花潮：`naturalMoonBloom`、`moonBloomDurationSeconds`、`moonVisitors`（送月人与小月亮）、`moonLanterns`（留灯）。
- 镜天巡礼：`naturalMirrorSky`、`mirrorSkyDurationSeconds`（默认 780，120–3600）、`mirrorVisitors`（旅人与错位路标）、`mirrorBeasts`（镜兽）、`mirrorGallery`（镜廊）。
- 绯线缝世：`naturalScarletSeam`、`scarletSeamDurationSeconds`（默认 780，120–3600）、`threadStrikes`（落针区）、`threadVisitors`（走针者与口袋）、`threadTug`（拉线牵引）。
- 无声白昼：`naturalSilentDaylight`、`silentDaylightDurationSeconds`（默认 720，120–3600）、`hushVisitors`（无声行列、敲门的空位与唯一的铃）。
- 苍翠梦潮：`naturalVerdantDream`、`verdantDreamDurationSeconds`（默认 780，120–3600）、`dreamVisitors`（花路与回眸、游荡的梦种与梦藤围场、失路叶鱼）。

| 云与天光 | 云先泛绿，森林长满后隐去（不抬高，以免越过树冠露出来）；天光染成柔和的翡翠绿，远处的雾与树冠在地平线处的雾同色 | `mixin/CloudVeilMixin`、`TideLightMixin`、`DreamClient#fog` |

预览工具使用工程目录中的独立 QA 世界，不读取玩家已有世界。默认自动拍摄六个阶段后退出，`detail` 检查近景、室内、手记和浮潮，`lifecycle` 将持续时间设为合法的 120 秒配置，逐 tick 运行所有阶段与遭遇。`art` 为美术复查：自动搭台并拍摄幽舟环绕视角、乘船、星鲸各角度与沉船近景、开幕云层、光瀑、浮潮两阶段、鲸鳞坠落、手记四个跨页、快捷栏图标与瓶中星海；`-PtidePreviewScenes` 按场景名前缀筛选。月骸花潮的美术场景以 `moon_` 开头，共拍摄 33 张（另有帧时间场景 `perf_moon`），舞台是在 QA 世界旁自动搭建的花园：各阶段天空、三月与碎月、花田、灯旁螺旋、室内门窗、送月人的环绕视角与近景、散开与重聚、献月、空位、诱饵、小月亮与星座、月影、手记月骸章节、快捷栏道具与银花灯。`moonlife` 将花潮设为合法的最短 120 秒，从自然触发开始逐 tick 走完整场，并执行所有遭遇与异常路径，结果写入 `run/moon-lifecycle.log`。镜天巡礼的美术场景以 `mirror_` 开头（约四十张，另有帧时间场景 `perf_mirror`），舞台是 QA 世界旁的小村：各阶段天空、昼夜、塔与门、空中镜片、裂镜与归天、巡礼者行走/停步/白天/暗影、棱镜视野、三面镜框与认对后、旅人、裂片预警与镜兽、镜廊三处、室内、残影、回响、镜灯、快捷栏、最后一片与手记。`mirrorlife` 以 150 秒的镜天从自然触发开始逐 tick 走完整场：先走一段路，再依次揭门、进出镜廊、认镜框、跟旅人、在裂片前退开与停留、迎上巡礼者的目光、在镜碎前被送出镜廊、接住最后一片，结果写入 `run/mirror-lifecycle.log`。绯线缝世的美术场景以 `thread_` 开头（四十余张，另有帧时间场景 `perf_thread`），舞台是 QA 世界旁的一片草地：石丘、树、小木屋、灯柱、水井与织天灯，覆盖各阶段天空与昼夜、伤口与针脚、金针入缝/转身/横穿、地平线细光、三处落针的预告/下落/余线、走针者三种状态、岩壁金缝、室内、线头、金针落地的远景与近景、拱起与回升、巨手阴影、拉线、胶片残影、三叶结、口袋与调律、星带、最后一片、织天灯、道具与方块、手记。`threadlife` 以 180 秒的缝世从自然触发开始逐 tick 走完整场：看裂天，走进第一处落针区再在落针前走出，留在第二处被击倒，带着系缚结留在第三处，接住线头，解开走针者的线结并接住三个线头，被拉线牵动，抬头看牵着自己的线，在口袋外和口袋里各放一次调律锚，接住最后一片，结果写入 `run/thread-lifecycle.log`。无声白昼的美术场景以 `hush_` 开头（四十余张，另有帧时间场景 `perf_hush_*`），舞台是 QA 世界南边的一片草地：带门廊雨篷与火把的小屋、两棵树、池塘、小路、灯柱与花，覆盖失声、灰潮、苍白天空的昼夜、灯火、室内、尘埃、水面、黑日升起/透镜/颜色细带/接触/全蚀/夜里的蚀、全蚀下的大地、无声行列的行走/近景/回应/仰望/无声提灯、敲门的空位的敲门/屋内/鞠躬/擦去、悬铃/颜色波纹/有声岛、白线与残像、悬羽、举灯、鸟、复声与天空复色、静烛、道具与方块、手记四个跨页。`hushlife` 以 240 秒的白昼从自然触发开始逐 tick 走完整场：看世界褪色并拿到手记，检查各类声音的增益，对门外的空位举灯并拿到白昼蜡，看悬在面前的羽毛，走到无声行列旁举灯并接住孩子留下的蜡，找到唯一的铃并站进有声岛，全蚀时在露天正对黑日举灯，看白线、等雷，捡起落下的铃与羽毛，结果写入 `run/hush-lifecycle.log`。苍翠梦潮的美术场景以 `dream_` 开头（约五十张，另有帧时间场景 `perf_dream_*`），舞台是 QA 世界旁的一片花田：小屋、麦田、池塘和几棵橡树，覆盖绒云、垂根、树冠长满与全貌、叶影、室内、叶鱼群与花纹、梦树的昼夜、花路、游荡的梦种、藤影围场与赢得之后、失路叶鱼与汇成金鱼、鹿之路、巨鹿的远景/行走/近景/腿/夜里/转身/回眸/鹿角、蹄印、金秋、落种与引种、枝影、归云、鹿角枝、道具与方块、种出的梦树、手记四个跨页。`dreamlife` 以 300 秒的梦潮从自然触发开始逐 tick 走完整场：看森林垂下并拿到手记，沿花路走到梦树下，碰游荡的梦种并追完五道光，把失路叶鱼引出来接住金叶，在树下安静等巨鹿回眸并接住梦种，把落下的梦种引到泥土和蹄印里，捡起鹿角枝，结果写入 `run/dream-lifecycle.log`。普通运行不启用预览工具。

可用 `-PtidePreviewWorld=VeilborneShaderQA` 指定另一个独立测试世界。附加 `-PtideCompat` 使用 `runs/compat` 的隔离副本（与实例中启用的模组一致）。双客户端验证使用 `runNetworkHost` 和 `runNetworkGuest`，仅监听本机 `127.0.0.1:25588`，测试结束会退出。

## 资源生成

```powershell
python tools/generate_assets.py               # 全部资源
python tools/generate_assets.py --no-sound    # 跳过声音
python tools/generate_assets.py --moon-sound  # 只重写月骸花潮的声音，星海的 OGG 不变
python tools/generate_assets.py --no-sound --moon-sky painting.png  # 换上绘制的月夜天空
python tools/generate_assets.py --mirror-sound  # 只重写镜天巡礼的声音
python tools/generate_assets.py --no-sound --mirror-sky painting.png  # 换上绘制的镜中远景
python tools/generate_assets.py --thread-sound  # 只重写绯线缝世的声音
python tools/generate_assets.py --no-sound --thread-sky painting.png  # 换上绘制的天衣
python tools/generate_assets.py --hush-sound  # 只重写无声白昼的声音
python tools/generate_assets.py --no-sound --hush-sky painting.png  # 换上绘制的苍白天空
python tools/generate_assets.py --dream-sound  # 只重写苍翠梦潮的声音
python tools/generate_assets.py --no-sound --dream-sky painting.png  # 换上绘制的深处林子
```

不带参数运行会重新合成星海的 OGG，内容相同但字节不同；只改了月骸、镜天、缝世、白昼或梦潮部分时请用 `--moon-sound`、`--mirror-sound`、`--thread-sound`、`--hush-sound`、`--dream-sound` 或 `--no-sound`。
